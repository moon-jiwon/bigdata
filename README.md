# 빅데이터 수업 실습

백석대학교 빅데이터 수업(2026학년도 2학기) 주차별 실습 노트북입니다.
Python(pandas, matplotlib, seaborn, scikit-learn)과 Jupyter Notebook으로 진행했습니다.

## 주차별 내용

| 주차 | 파일 | 내용 |
|---|---|---|
| 1주차 | `week01_1` | pandas 기초 (데이터 불러오기, 열 선택, 조건 필터링, 정렬) |
| 2주차 | `week02_1` ~ `week02_3` | matplotlib 시각화, 코로나 데이터, groupby |
| 3주차 | `week03_1` | Netflix 데이터 분석 (결측값 처리, value_counts, groupby, 워드클라우드) |
| 4주차 | `week04_1`, `week04_2` | seaborn 시각화, Netflix EDA |
| 5주차 | `week05_1` | Netflix 데이터 가공 (날짜 변환, 문자열 처리, explode) |
| 6주차 | `week06_1` | 서울 상권 데이터 분석 |
| 7주차 | `week07_1` | 서울 상권 분석 (커피 브랜드 비교, folium 지도) |
| 8주차 | `week08_1` ~ `week08_3` | 딕셔너리, pandas 정리, 미세먼지 Open API 수집과 분석 |
| 9주차 | `week09_1` ~ `week09_3` | 미세먼지 연도별 수집(2020~2025), train_test_split, iris KNN |
| 10주차 | `week10_1` | 유방암 데이터 분류 (KNN, 결정트리, 랜덤포레스트) |
| 11주차 | `week11_1`, `week11_2` | 분류 평가지표(정밀도, 재현율, F1), 중고차 가격 회귀 |
| 12주차 | `week12_1` ~ `week12_3` | 회귀 모델 비교, 미세먼지 분류·회귀, 기상청 Open API 수집과 머신러닝 |

## 실행 방법

각 주차 폴더 안에 노트북과 사용한 csv 파일이 같이 있습니다.
폴더 안에서 노트북을 열고 위에서부터 차례로 실행하면 됩니다.

## 참고

- **API 키:** Open API를 사용하는 노트북(`week08_3`, `week09_1`, `week12_3`)의 키는 `여기에_본인_API키_입력`으로 바꿔두었습니다. 공공데이터포털에서 발급받은 키를 넣어서 실행하세요.
- **6·7주차 데이터:** 서울 상권 데이터는 원본 csv가 80MB 이상이라 `.csv.xz`로 압축해서 올렸습니다. pandas가 압축된 파일을 바로 읽기 때문에 압축을 풀지 않고 그대로 실행하면 됩니다(`pd.read_csv('서울상권.csv.xz')`). 원본은 공공데이터포털의 소상공인시장진흥공단 상가(상권)정보입니다.
